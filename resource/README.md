# 资源目录

- `i18n/`：多语言包（简体中文 zh_CN / 英文 en_US，预留多语言扩展接口，新增语言只需添加 JSON）
- `themes/`：主题配色资源（浅色 light / 深色 dark，主题通用主色在代码 `config.theme.COMMON_COLORS` 中定义）
- `icons/`：图标资源

## 主题通用主色（三套主题通用）

| 用途 | 名称 | 十六进制 | RGB |
| --- | --- | --- | --- |
| 主色（科技蓝） | primary | #1677FF | 22,119,255 |
| 辅助色（青绿） | success | #36CFC9 | 54,207,201 |
| 警示色（橙红） | warning | #FF7D00 | 255,125,0 |
